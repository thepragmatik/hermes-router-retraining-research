SEMANTIC ROUTING VERDICT

Yes—but as the coordinate system, not the oracle.

Naive prompt-cluster → model selection is falsified-adjacent. The viable form uses semantics to describe task/domain/complexity, retrieve measured historical outcomes, quantify OOD support, calibrate judges and allocate label budget.

Rejected form

prompt embedding→cluster / nearest intent→weak or strong

This is too close to the failed cluster router and assumes semantic similarity implies model complementarity.

Recommended form

semantic signals→performance memory + support→value model

Semantics locates trustworthy evidence; outcomes determine model value. Read the review →

RISK-RETIREMENT QUEUE · $0 FIRST

Falsify the architecture before paying for labels.

The highest-value next step is not another API run. It is a train-only audit that reveals whether strong actually rescues weak failures consistently enough for weak correctness to stand alone.
